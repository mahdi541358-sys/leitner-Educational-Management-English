# جعبه لایتنر درس زبان انگلیسی تخصصی پیشرفته - رشته مدیریت آموزشی

ساخت APK با GitHub Actions:
1. در github.com یک مخزن (Repository) جدید بسازید.
2. همهٔ فایل‌های این پوشه (از جمله پوشهٔ پنهان `.github`) را در مخزن آپلود کنید.
3. به تب **Actions** بروید؛ ساخت به‌صورت خودکار شروع می‌شود (یا Run workflow را بزنید).
4. پس از تمام شدن (حدود ۵ تا ۸ دقیقه)، از پایین صفحهٔ همان اجرا، فایل **Leitner-Box-APK** را دانلود و از حالت ZIP خارج کنید.
5. `Leitner-Box.apk` را روی گوشی نصب کنید (اجازهٔ نصب از منبع ناشناس لازم است).
